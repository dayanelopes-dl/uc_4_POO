SISTEMA ESCOLAR - PYTHON POO

Estrutura:
- pessoa.py -> classe Pessoa
- aluno.py -> classe Aluno
- professor.py -> classe Professor
- escola.py -> classe Escola
- main.py -> programa principal

Conceitos:
- Programação Orientada a Objetos
- Herança
- Encapsulamento
- Métodos
- Regras de negócio

Regras de negócio:
1. O aluno precisa ter pelo menos 6 anos para ser matriculado.
2. O aluno precisa ter média maior ou igual a 7.0 para ser aprovado.

Como executar:
1. Abra o terminal na pasta do projeto.
2. Execute:
   python main.py
